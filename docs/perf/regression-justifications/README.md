# Begründungen absichtlicher Qualitätsänderungen

Eine Datei in diesem Verzeichnis ist nur für eine bewusst akzeptierte
Verschlechterung einer Nicht-Safety-Metrik zulässig. Sie muss die alte und
neue Grenze, alle betroffenen Korpuszeilen, den fachlichen Grund, Alternativen,
Review und Commit nennen. Safety-Grenzen dürfen niemals auf diesem Weg
gelockert werden.
